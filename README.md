##### 这是一个企业级AI智能助手

### 项目主简介

项目主要为了满足企业的知识库系统RAG，企业智能数据报表图表，以及和AI闲聊等功能。系统采用云原生开发框架，前后端分离架构。系统既方便服务横向扩展，也方便随业务增长而实现微服务拆分部署。

### 系统架构简介

智能助理：与AI交互入口，主要涉及对话与上下文管理，支持多能对话。意图识别，准确判断用户的输入，判断命令意图。工具调用，可以通过MCP接入外部插件，富响应生成通过用户输入的文本可以生成文本内容、表格以及图标。
知识中枢RAG：处理飞结构化知识。解决AI对于特定知识、个性知识无法正确判断等问题。主要包括文档处理流程，包括多文件格式上传，自动解析，自动分块，向量化，向量存储。
数据图表分析：处理结构化数据并生成响应图表，提供NL2SQL引擎，将自然语言转化成SQL查询。自动生成可视化图表，利用LLM总结图表得出相关报告并导出。
MCP接入管理：负责对接外部系统接口。实现MCP服务注册。并且提供相关权限确保操作安全。

## 项目技术：
整体技术：云原生开发 .NET Aspire
AI技术栈：Microsoft Agent Framework
知识库：向量数据库使用Qdrant，关系型数据库使用pgsql，文档排队处理：RabbitMQ
大模型：兼容OpenAI接口，支持私有化部署
安全方案：JWT+RABC
系统架构：整体采用前后分离，分为5个层次。分别是UI层，接入层（webApi）、业务服务处（数据报表服务、MCP插件服务、AI网关、知识中枢）、基础设施层（pgsql操作，向量数据库，消息队列，文件存储）、外部服务（MCP服务器 ）
